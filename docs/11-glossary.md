# Technical Glossary: Sachidaanand Hospital

- **BMI (Body Mass Index)**: A screening metric calculated as weight in kilograms divided by height in meters squared.
- **HIPAA**: Health Insurance Portability and Accountability Act regulating the confidentiality and security of Protected Health Information (PHI).
- **MPA (Multi-Page Application)**: A web architecture where every user interaction or route change loads a distinct HTML document from the server or cache.
- **Panic Button**: A dedicated high-priority UI component executing immediate SOS notifications and location broadcasts.
- **WebRTC**: Real-Time Communication standard enabling browser-to-browser peer-to-peer audio, video, and data streaming.
